# NextGen-Helfer

Projektbasis fuer **Isya Gold**, einen externen Fiesta-Online-Wirtschaftsassistenten.

- Windows-Anwendung mit nativer C++20-Build-Pipeline
- Daten und Guides mit Quellenangaben; veraltete Wiki-Informationen sind als solche gekennzeichnet
- Keine Spielautomation, keine Client-Injektion, keine automatischen Eingaben

Der Hauptbranch `main` bleibt der Einstiegspunkt. Neue Arbeit entsteht auf Feature-Branches und wird per Pull Request geprueft.
